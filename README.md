## 🚀 Featured Projects

### 🤖 [MarketPilot AI](https://github.com/vinakodiyatar/marketpilot-ai-backend)
**AI Marketing SaaS & Backend Platform**  
An AI-powered marketing platform designed around multi-provider AI orchestration, reliable API workflows, and automated marketing deliverables.

**Key Features:**
- Gemini as primary AI provider
- Automatic Mistral AI fallback
- Retry and exponential backoff
- HTTP 429 / rate-limit handling
- Multi-tenant JWT authentication
- User/Admin RBAC
- Usage quota enforcement
- API rate limiting
- MongoDB data isolation
- Structured AI responses
- Google Ads generation
- SEO strategy generation
- PDF and DOCX export
- Administrative usage analytics

**Tech:** `Node.js` • `Express.js` • `MongoDB` • `Gemini` • `Mistral AI` • `JWT` • `REST APIs`  
👉 🔗 **[Live Website](https://mern-ai-saas-frontend.vercel.app/) • 📁 **[View Repository](https://github.com/vinakodiyatar/marketpilot-ai-backend)**

### 🍳 [MoonWalk Kitchen](https://github.com/vinakodiyatar/moonwalk-kitchen)
**Resource-Aware Restaurant Scheduling System**  
A backend scheduling system that calculates order completion times while considering kitchen backlog, preparation time, and required resources.

**Key Features:**
- FIFO Resource Queue
- Shortest Job Next (SJN)
- Resource-aware scheduling
- Kitchen backlog calculation
- Dynamic ETA calculation
- Resource contention handling
- Execution tracking
- SQLite persistence

**Tech:** `Node.js` • `SQLite` • `better-sqlite3` • `Scheduling Algorithms`  
• 📁 **[View Repository](https://github.com/vinakodiyatar/moonwalk-kitchen)**
